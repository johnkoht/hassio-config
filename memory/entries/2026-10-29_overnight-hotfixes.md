# Overnight hotfixes, 2026-10-29

Small bugs found by the 10-28 investigations and the dead-entity audit, each through /hotfix and /wrap.

- **critical_announcement auto skipped the main bedroom.** The auto branch read the nonexistent `input_boolean.main_bedroom`, so the leak voice alert (`media_players: auto`) never played there. Now `main_bedroom_occupied`.
- **Front door left-open alert and porch camera detections watched nonexistent entities.** `doors_left_open` used `front_door_status` (live: `front_door`), so only the garage door could alert; porch person/animal triggers used `backyard_porch_camera_*_detected` (live: `backyard_porch_*_detected`), so they never notified. Porch alerts now arrive. Backlog: porch `proxy_camera` source is wrong; `timer.finished` re-alert lacks `trigger.from_state`.

**Learning:** `tests/test_entity_references.py` would catch this whole class, but it skips without a registry snapshot. That's the cheapest route to a dead-entity CI check.
- **Dead entity references, batch 2 (audit HIGH/MEDIUM).** Renamed to live entities: Cristina's reload "Just Left" reset, NWS active sensor, the three birthday reminders (`calendar.birthdays`), the `group.familiy` typo in three arrival-heater automations, and foyer `"Bedtime"` casing. Left for John: the UV alert (dead, broken templates, noisy if revived), Tempest rain sensors (unit mismatch), personal-time/garbage/work calendars, presence trackers, Nino bathroom heater temperature sensor, family_room select options, `cameras_available`, porch proxy camera.
- **Door left-open re-alert after a snooze never fired.** The `timer.finished` event trigger has no `trigger.from_state`, so both messages failed to render and the run aborted. They now name the open doors from an `open_doors` variable (`expand`). Test renders both triggers with real Jinja2. Backlog: plural wording ("has" with two doors).
- **Main bedroom light switch-off started Bedtime with nobody in bed (JK-709).** The light-off trigger passed the `or` condition whenever house `bedtime` was still on, so a morning switch-off sent the room Wake, then Bedtime four seconds later. A new condition makes the light-off trigger count only when someone is in bed or Just Laid Down; the other triggers are unchanged. Test renders the condition with real Jinja2. Backlog: the test doesn't assert the condition stays at top level.
- **Severe rain warning fired on snow (JK-876).** `severe_rain_incoming` triggers on precip intensity and accumulation (0h and 1h) and never checked the type, and accumulation counts snow. A new condition skips the alert when the triggering hour's `sensor.pirateweather_precip_<hour>` is snow or sleet; it fails open on any other value. Test renders the condition with real Jinja2. Backlog: confirm the sensor reports exactly `snow` on the first real snow day.
