# PRD: protect-detection-watchdog

Source: plan.md (threshold changed from 3 h to 6 h on recorder evidence, see pre-mortem.md), pre-mortem.md, review.md.

1. `packages/security/cameras/protect_watchdog/protect_detections_stale.yaml`: trigger-based template `binary_sensor.protect_detections_stale` (unique_id/default_entity_id). Triggers: time_pattern minutes /15, homeassistant start, event_template_reloaded. State: on when the newest `last_changed` among the seven motion sensors (front_door_camera_motion, driveway_front_camera_motion, garage_driveway_camera_motion, backyard_south_camera_motion, backyard_porch_motion_2, backyard_pool_motion_2, backyard_northwest_motion_2), skipping unavailable/unknown/missing, is older than 6 h. Unavailable if all seven are missing. Attribute: newest motion time. A start or reload trigger never yields `on` (restored last_changed is the restart time, so this falls out naturally; test it).
2. `packages/security/cameras/protect_watchdog/protect_detection_watchdog.yaml`: id `protect_detection_watchdog`. Trigger stale `to: on`, `not_from: [unavailable, unknown]`. Condition: `this.attributes.last_triggered` is none or older than 6 h. Actions: `homeassistant.reload_config_entry` targeting `binary_sensor.backyard_pool_motion_2` with continue_on_error; `wait_for_trigger` on any state change of the seven sensors, timeout 60 min, continue_on_timeout. If one changed: passive push to John ("Camera detections had frozen; UniFi Protect was reloaded and they're back"). Else: time-sensitive push to John ("Camera detections are frozen and a reload didn't fix them. Camera alerts and the garage auto-lock's outside check are blind. Check the NVR.") Both: script.general_notification, devices "jk", tag `protect-watchdog`, url to the security cameras page.
3. Check `to: "off"` triggers on Protect sensors in the garage evening auto-lock and garage flood-light automations for `not_from: [unavailable, unknown]`; add the guard where missing (that is the reload's only side effect), with a test.
4. Dashboard: a Detections row on `dashboards/kohbo/security/cameras/cameras.yaml` showing the stale sensor and its newest-motion attribute.
5. Tests: staleness maths (fresh, 5 h, 7 h, some unavailable, all missing), throttled triggers (mirror test_sensor_health_is_throttled), the guard, the wait, push priorities, deep link (add to the deep-link test map if needed), the not_from guards.
6. Docs: packages/security/cameras/README.md, packages/security/LEARNINGS.md, plan Risks section (add the unavailable→off transition and the post-restart blind spot), and the memory note reference_unifi_protect_doorbell_is_event_entity.md (no IPs in new text).
